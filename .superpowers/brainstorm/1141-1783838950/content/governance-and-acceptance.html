第一版验收主线
  1. 两个平台用户各自创建多个 Agent，数据、Skill、Connector 与密钥严格隔离。
  2. Agent 只填写 AGENT.md 或 SOUL.md 也可发布；发布后草稿修改不影响线上。
  3. 不配置飞书也能生成 Agent API Key，并完成多轮、流式和异步调用。
  4. 发布后绑定独立飞书应用，私聊用户和群聊会话互相隔离且不产生长期记忆。
  5. 重新发布、回滚不改变飞书机器人、API URL、API Key 与已有 conversation_id。
  6. 公开/私有 Skill 只能访问明确授权的 Connector capability，越权调用被拒绝并审计。
  7. 可选 Agent 限额与强制平台硬上限均能正确拦截，重复事件和重复请求不会重复计费。
