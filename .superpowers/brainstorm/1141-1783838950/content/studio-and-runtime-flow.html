飞书消息链路
  1. 独立机器人收到事件，验签并按 event_id 去重。
  2. Channel Binding 解析稳定 agent_id。
  3. 按飞书用户/私聊/群聊映射独立 thread。
  4. 检查 Agent 状态、每日额度与并发。
  5. 加载 current_release 快照并调用 Runtime。
  6. 流式更新飞书消息，记录用量与审计。
External API 链路
  1. Bearer Key 哈希匹配到稳定 agent_id。
  2. Idempotency-Key 去重，执行 Key 级与 Agent 级限额。
  3. conversation_id 隔离调用方会话。
  4. 固定加载 current_release；禁止覆盖 Skill/模型/上下文。
  5. 支持同步、SSE 流式和异步 Run 查询。
  6. 响应只展示稳定 Agent 身份，不暴露内部 Release。

与现有项目的衔接

  • 保留现有 Agent 页面和对话式创建能力，但重构为可直接编辑的 Studio 草稿。
  • 复用现有 Skill 列表、LangGraph RunManager、流式事件和飞书适配器。
  • 现有全局 ChannelService 改为数据库驱动的多实例 Supervisor，可按单个 Agent 热启停。
  • 现有 External API 的 Conversation/Run 能力下沉复用，新增 Agent 专属稳定 API 门面。
