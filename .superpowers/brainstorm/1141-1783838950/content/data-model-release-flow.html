发布校验

  • AGENT.md 与 SOUL.md 至少有一个非空，组合 Prompt 通过大小与安全检查。
  • 选中的公共/私有 Skill 必须存在且锁定到具体修订；私有 Skill 必须归创建者所有。
  • Skill 声明的 Connector capability 必须全部获得 Agent 级授权。
  • 模型、额度、并发、超时必须有效；飞书凭据可先保存，但启用渠道前必须连通性校验成功。
