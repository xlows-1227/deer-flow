核心约束

  • 外部请求永远不能通过参数切换 Agent、版本、Skill 或 Connector。
  • 运行时使用 Agent 创建者的资源授权，但禁用全部长期记忆读写。
  • 飞书用户和群聊只隔离会话；共享的是发布快照，不共享聊天上下文。
  • 一个 Agent 的渠道异常、额度耗尽或密钥轮换不影响其他 Agent。
